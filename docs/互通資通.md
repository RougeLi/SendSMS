# 互動資通簡訊API

## 1. 驗證系統作業

### 1.1 取得連線憑證

* **URL**：`https://[SiteUrl]/[custcode]/getoken`
* **Method**：`POST`
* **Content-Type**：`application/json; charset=utf-8`
* **Request Body**:

  ```json
  {
    "uid": "<帳號>",
    "pwd": "<密碼>"
  }
  ```
* **Response Body**:

  ```json
  {
    "status": "200",
    "message": "success",
    "data": {
      "token": "<token>"
    }
  }
  ```

## 2. 文字簡訊服務 (SMS)

### 2.2 一般簡訊

* **URL**：`https://[SiteUrl]/[custcode]/sendsms`
* **Method**：`POST`
* **Content-Type**：`application/json; charset=utf-8`
* **Request Body**:

  ```json
  {
    "uid": "<帳號>",
    "pwd": "<密碼>",
    "subject": "<簡訊主旨>",
    "msg": "<簡訊內容>",
    "mobiles": "+886900000001,+886900000002",
    "sendtime": "",

  }
  ```

## 6. 互動回覆簡訊 (Safesay)

### 6.1 取得互動回覆簡訊連線憑證

* **URL**：`https://[SiteUrl]/v2/[Pack]/gettoken`
* **Method**：`POST`
* **Content-Type**：`application/json`
* **Request Body**:

  ```json
  {
    "Account": "<帳號>",
    "Password": "<密碼>"
  }
  ```
* **Response Body**:

  ```json
  {
    "Result": true,
    "Msg": "<JWT Token>"
  }
  ```

---

### 6.2 發送訊息

* **URL**：`https://[SiteUrl]/v2/sendMessage`
* **Method**：`POST`
* **Headers**:

  ```
  Authorization: Bearer <token>
  ```
* **Request Body**:

  ```json
  {
    "EventID": 22,
    "Mobile": "+886900000001",
    "Text": "訊息內容"
  }
  ```
* **Response Body**:

  ```json
  {
    "Result": true,
    "MessageID": "eff1d50-8814-4f17-aa61-cb23b97987fa",
    "MessageTime": 1729133590209232
  }
  ```

---

### 6.3 檔案下載

* **URL**：`https://[SiteUrl]/v2/downLoadFile`
* **Method**：`POST`
* **Headers**:

  ```
  Authorization: Bearer <token>
  ```
* **Request Body**:

  ```json
  {
    "FileID": "<檔案ID>",
    "Mobile": "<手機號碼>",
    "ChatroomID": "<聊天室ID>"
  }
  ```
* **Response**：回傳檔案串流，可下載
